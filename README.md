# Best FreeElec To-Do List (No Node.js)

A simple To-Do List made with plain HTML, CSS and JavaScript.

## Run

No Node.js or npm is required. Open `index.html` in a web browser.

Tasks are stored in the browser's localStorage.

## Features

- Add tasks
- Mark tasks complete
- Delete tasks
- Clear completed tasks
- Persistent tasks using localStorage
- Responsive layout
